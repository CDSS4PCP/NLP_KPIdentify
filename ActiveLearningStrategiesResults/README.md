# Active Learning Experiment Results

This folder contains the results of experiments conducted for each Active Learning strategy. Each strategy's results are stored in separate **.xlsx** files.

## File Structure
Each **.xlsx file** consists of multiple sheets, structured as follows:

- **Sheet 1 (Individual Experiment Results):**
  - Contains detailed results of the experiment, including performance metrics across Active Learning cycles.
  - Lists the **Experiment Settings** used for the specific experiment.

- **Summary Sheet (Aggregated Results):**
  - Provides a **summary** of the individual experiment results.
  - Includes averaged performance metrics and key observations.

## Usage
To analyze the results:
1. Open the respective **.xlsx file** for the strategy you wish to review.
2. Refer to **Sheet 1** for detailed experiment settings and cycle-wise results.
3. Check the **Summary Sheet** for an overview of the experiment’s performance trends.

These results help evaluate the effectiveness of different Active Learning strategies based on recall, F1 score.
